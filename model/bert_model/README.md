
# Fine-tuned BERT Sentiment Model

This folder contains the configuration and tokenizer
for our fine-tuned BERT sentiment classification model.

## Model Details

- Architecture: BERT Base Uncased
- Framework: HuggingFace Transformers
- Task: Three-class sentiment classification
- Classes: Negative, Neutral, Positive

## Download Model Weights

The complete trained BERT weights are available
in GitHub Releases because of their large size.

[Download BERT Model (387 MB)](https://github.com/ananyakannojia/amazon-review-sentiment-analysis/releases/download/v1.0.0/bert_model.zip)

After downloading, extract the ZIP into this folder.
